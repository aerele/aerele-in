Lens

The product - what we built so the same eyes that review Frappe core can look at your code too.

Every check Lens runs is informed by the work we do every day on the framework itself. When the audit flags a deprecated API, it's because we've watched it deprecate. When it warns about a breaking change, it's because we've reviewed - and often written - the patch upstream.

Why this matters

Built by the team that contributes to the framework you run on.

Lens is the first tool in a small line of products built on top of our work in the Frappe ecosystem. The same engineers who contribute upstream build them - which means they're built right.
